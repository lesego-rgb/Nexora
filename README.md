## Nexora - Daily Social Suggestions by Makgao Ramolotja(10515494)
### Nexora is a simple Android application designed to help users stay socially active by providing predefined interaction suggestions based on the time of day.

🚀 Features
Smart Input: Uses an AutoCompleteTextView to provide a dropdown list of suggestions as the user types.

Dynamic Suggestions: Maps specific times of day (Morning, Afternoon, etc.) to social action items.

Input Validation: A when block handles user input, including error handling for empty or invalid entries.

One-Tap Reset: Quickly clear the interface to start over.

Developer Logging: Includes Log.d tags to track user interaction in Logcat.

🛠️ Built With
Kotlin - Programming language.

Android Studio - Development environment.

XML - UI Layout design.

Material Components - For a modern look and feel.

## Purpose
Nexora aims to make socialising easier by giving you simple, helpful suggestions for reaching out to others throughout your day. It takes the guesswork out of staying in touch by providing quick ideas, like sending a friendly text or calling a relative. This helps you keep your connections strong without feeling overwhelmed by what to say or when to say it.
